# Login_Form-Basics-
## 🔐 Simple Login Form
A responsive and interactive login form built using HTML, CSS, and JavaScript. This project demonstrates basic client-side form handling and validation.

## 📂 Project Structure
.
├── index.html     # Main HTML file with the form
├── style.css      # Styling for the login form and footer
└── index.js       # JavaScript for basic validation
🌟 Features
Simple and clean login form

Client-side validation to ensure all fields are filled

Responsive layout using pure CSS

Sticky footer with dynamic copyright

## 🧪 How It Works
When the form is submitted, JavaScript prevents the default behavior.

If both the username and password fields are filled, an alert shows "Login is Success".

Otherwise, it prompts the user to fill in both fields.

## 🚀 Getting Started
1.Clone or download this repository.

2.pen index.html in your browser.

3.Fill in the form and try submitting it to see validation in action.
